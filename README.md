# One Image, Friday 27 November 2026

Entry for the [news-image-20261127](https://make.fun/bounty/news-image-20261127) bounty on make.fun: the whole world of Friday 27 November 2026 in a single 1024×1024 image.

50 sourced stories from 10 regions across 22 fields, drawn as 15 vector scenes with a UTC timeline and a date check — every story first reported on Friday 27 November 2026, in any timezone. No image API, no outside assets: the program draws everything itself (pixel canvas, a hand-built 5×7 bitmap font, and a PNG encoder, Node standard library only).

## The program

`main.ts` writes the image to `/output/entry.png`.
